Collector Function workload

Current Terraform provisions one fixed B2 collector worker with Always On, separate from the dashboard plan. Compute is paid continuously, not by GB-seconds or Durable activity count. The current schedule is daily at 05:00 UTC. Rates use 730 planning hours; adjust hours/days for the month being budgeted. Duration is a scheduling/capacity check only: the observed 30.35-minute normalization activity was not a complete run duration. Calculator inputs do not change deployment settings.

Dashboard Web App

The current deployment profile uses one always-on Linux B2 Web App. Easy Auth, managed identity, role assignments, and the Entra app registration have no separate resource meter in this model.

Protected immutable history storage

Published-object floor: one write per published file plus run manifest/current pointer, and two verification reads per file (manifest + file). Add HTTP checkpoints, processing artifacts, retries, baseline/viewer downloads, block/chunk transactions, and list/create-container operations separately; file count is not total billable transactions. Zero overhead allowances are unmeasured, not evidence of zero cost. The bounded option is hypothetical only: it never configures deletion or guarantees Azure immutability permits it.

Function runtime storage

This is the separate replaceable StorageV2 LRS account used by the Functions host, trigger monitor, queues/tables, and deployment package. It is not retained DVM evidence.

Application Insights and Log Analytics

Includes collector heartbeats, row/substep progress, Durable activity diagnostics, traces, requests, and exceptions. Terraform currently routes Function diagnostics to Log Analytics, not Web App startup logs. If Web App diagnostics are enabled, include their measured volume under other telemetry. The paid Analytics ingestion tier is $2.76/GB; the public first-5-GB credit is shared and may already be consumed, so no project credit is assumed. Do not select the API's $0 free-tier meter as the paid rate.

Network, licensing, support, and optional architecture

The current Terraform does not deploy Front Door, WAF, NAT Gateway, private endpoints, Private DNS, or a secondary region. Defender and Entra licenses are external prerequisites, so enter only incremental costs attributable to this project.
