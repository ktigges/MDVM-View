Recognized cost drivers: location, memory, schedule, replication, immutability/soft-delete days, Web App SKU, deployment stages, tracking, mode, cache, and subscription-reader count. Naming, tags, RBAC, identities, app registration, and containers are reported as no-direct-charge configuration.

Collector Function workload

Current Terraform sets one FC1 Flex Consumption instance maximum and configures no Always Ready instance. The calculator frequency does not change the deployed NCRONTAB schedule.

Dashboard Web App

The deployed design uses one always-on Linux B1 Web App. Easy Auth, managed identity, role assignments, and the Entra app registration have no separate resource meter in this model.

Protected immutable history storage

Includes raw pages, curated datasets, recommendation lifecycle events, compact run history, manifests, retained SLA policy, current-pointer writes, and append-only recommendation workflow events. The two lifecycle files add two writes per run and a conservatively modeled 0.001 GiB; replace the run-size input with measured bundle size after the first upgraded run. The bounded option changes estimates only; it does not configure deletion.

Function runtime storage

This is the separate replaceable StorageV2 LRS account used by the Functions host, trigger monitor, queues/tables, and deployment package. It is not retained DVM evidence.

Application Insights and Log Analytics

Terraform uses workspace-based Application Insights, Log Analytics PerGB2018, 30-day retention, diagnostics, traces, requests, exceptions, and Function metrics. The reporting upgrade adds only two short version messages per collection; existing progress telemetry remains the dominant run-specific log volume. Refresh rates for Central US before purchase.

Network, licensing, support, and optional architecture

The current Terraform does not deploy Front Door, WAF, NAT Gateway, private endpoints, Private DNS, or a secondary region. Defender and Entra licenses are external prerequisites, so enter only incremental costs attributable to this project.

  • User-assigned managed identities, Azure RBAC assignments, Defender/Graph app-role assignments
  • Entra application, service principal, app roles, and Easy Auth secret rotation object
  • Current manifest pointer capacity beyond the storage/operation inputs above
